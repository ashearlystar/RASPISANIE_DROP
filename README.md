# RASPISANIE DROP

Игровая оболочка для расписания занятий: кейсы, рулетка, инвентарь, Upgrader, контракты, профиль и настройки.

## Запуск

Проект использует JSON-файлы из `data/`, поэтому его нужно открывать через локальный HTTP-сервер, а не двойным кликом по `index.html`.

### Python

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере из этой папки.

### VS Code

Можно запустить папку через расширение Live Server.

## Исправления в этой версии

- восстановлена геометрия рулетки; ширина карточек и расстояние между ними считываются из реального layout, а выигрышная карточка центрируется под указателем;
- исправлен список групп: в выборе доступны все группы, для которых в `data/` есть расписание;
- расписание продолжает загружаться из `data/<группа>.json` и отображается после выпадения предмета;
- исправлена подпись для полного расписания;
- добавлена адаптивная компоновка для узких экранов, safe-area отступы и защита от горизонтального переполнения;
- на мобильных устройствах домашняя страница прокручивается целиком, без наложения карточек друг на друга.

Данные игрока хранятся в `localStorage` текущего браузера.


## Новые настройки кейсов и коллекций

- В рулетке расписаний есть переключатель «Быстрая прокрутка».
- В инвентаре добавлена сортировка «По дням» и блок прогресса сборки: показывает, сколько частей уже есть и сколько ещё требуется.
- Кнопка «Сундук» у телифона заменена на переход к шести коллекциям кейсов.

### Как настраивать коллекции

Все параметры находятся в начале `app.js`, в массиве `COLLECTION_CASES`. Для каждого кейса отдельно редактируются:
- `name` — название;
- `price` — стоимость в `tele.coins` (телифокоинах);
- `image` — изображение обложки;
- `rewards` — список скинов;
- у каждого скина `id`, `name`, `img` и `chance` (относительный вес выпадения).

Чтобы добавить или убрать скины, добавьте или удалите объекты в `rewards`. Шансы нормализуются автоматически: например, веса 50/30/20 дают вероятности 50%/30%/20%. Изображения сейчас используют заглушку `assets/telifon.png` — замените `img` и `image` на пути к готовым файлам. `id` каждого скина должен быть уникальным во всех коллекциях.
